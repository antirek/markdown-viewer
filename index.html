Отдельное приложение на Ubuntu

  1. Откройте сайт в Google Chrome или Chromium.
  2. Нажмите «Установить» или меню Chrome ⋮ → Установить приложение….
  3. Закройте вкладку и запускайте Markdown Viewer из меню приложений (или chrome://apps).
  4. ПКМ по .md → «Открыть с помощью» → Markdown Viewer → «Всегда».
