Отдельное приложение на Ubuntu

  1. Откройте сайт в Google Chrome или Chromium (не Firefox).
  2. Нажмите «Установить как приложение» здесь или меню Chrome ⋮ → Установить приложение… / Install Markdown Viewer….
  3. Закройте вкладку. Запускайте Markdown Viewer из меню приложений GNOME (Activities → поиск «Markdown») или из chrome://apps.
  4. Окно должно быть без адресной строки. В переключателе окон оно может всё ещё группироваться с Chrome — это ограничение Linux, но это уже app-режим.
  5. ПКМ по .md → «Открыть с помощью» → Markdown Viewer → «Всегда».

Через терминал (имя .desktop из ~/.local/share/applications/):

ls ~/.local/share/applications/ | grep -i chrome
xdg-mime default chrome-XXXX-Default.desktop text/markdown
